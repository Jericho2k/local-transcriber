![Чёрно-белый интерфейс Local Transcriber](assets/screenshot.png)

Без платного API, ключей и аккаунта в сервисе распознавания. Речь обрабатывает **faster-whisper на вашем компьютере**. На входе — локальная запись или одна ссылка YouTube; на выходе — текст, таймкоды, SRT и JSON.

## Для длинных записей

- **Локальный интерфейс в браузере:** история задач, прогресс, предпросмотр, журнал и выгрузка результатов.
- **Продолжение после остановки:** каждый завершённый 10-минутный блок сохраняется атомарно. Тот же источник с тем же языком использует уже готовые блоки.
- **GPU и CPU:** автоматический выбор устройства, ускорение NVIDIA CUDA и отдельный режим CPU.
- **Текст на языке записи:** автоопределение языка, английский/русский в интерфейсе и дополнительные коды языка в CLI. Перевода эта версия не делает.
- **Готовые субтитры не нужны:** программа распознаёт сам звук.

## Быстрый старт

**Windows x64 · Python 3.11 · FFmpeg**

Установите [Python 3.11 x64](https://www.python.org/downloads/windows/) и [FFmpeg](https://ffmpeg.org/download.html). Команды `ffmpeg` и `ffprobe` должны быть доступны в PATH. [Node.js](https://nodejs.org/) необязателен, но нужен для части загрузок с YouTube.

```powershell
git clone https://github.com/Jericho2k/local-transcriber.git
cd local-transcriber
.\INSTALL.cmd
.\START.cmd
```

Можно скачать ZIP репозитория, распаковать его и дважды нажать **INSTALL.cmd**, затем **START.cmd**.

Установщик создаст отдельное окружение `.venv`, загрузит закреплённую версию модели (около 1,6 ГБ), проверит её и запишет настройки для вашего компьютера. Для первоначальной установки с GPU стоит иметь **около 8 ГБ свободного места**, плюс место для записей. Python и FFmpeg установщик самостоятельно не устанавливает.

В браузере откроется локальная сессия на `127.0.0.1`. Выберите запись или вставьте одну ссылку YouTube, укажите язык и нажмите **Start transcription**. Для YouTube скачивается аудиодорожка; распознавание локального файла после установки работает без интернета.

### Где результат

В `output/` создаётся отдельная папка каждой задачи:

| Файл | Содержимое |
|---|---|
| `transcript.txt` | Обычный текст |
| `transcript.timestamps.txt` | Текст с таймкодами |
| `transcript.srt` | Субтитры |
| `transcript.json` | Фразы, тайминги и метаданные |

Файлы обновляются после готовых блоков и могут содержать частичный результат. Предпросмотр показывает ограниченный конец текста; выгрузка содержит весь сохранённый текст. При остановке завершённые блоки остаются, незавершённый блок обрабатывается повторно. Для продолжения сохраните `parts/` и скачанную аудиодорожку.

## Командная строка

```powershell
.\TRANSCRIBE.cmd "D:\media\interview.mp4" --language en
.\.venv\Scripts\python.exe -I app.py "D:\media\interview.mp4" --device cpu
.\.venv\Scripts\python.exe -I app.py --help
```

Доступны `--language auto|en|ru|...`, `--device auto|cuda|cpu`, `--output`, `--chunk-seconds`, `--beam-size`. **CHECK.cmd** проверяет загрузку модели без обработки записи.

Для установки без NVIDIA-библиотек запустите `INSTALL.cmd --cpu`: автоматический выбор устройства будет предпочитать CPU. На CPU работа медленнее; время зависит от записи и оборудования.

## Приватность и безопасность

Аудио **не отправляется провайдеру распознавания**. Установка обращается к PyPI и Hugging Face, а загрузка YouTube — к YouTube и его медиасерверам. Само распознавание использует модель на диске.

- Интерфейс доступен только через loopback, защищён случайным токеном сессии, проверяет origin/host и использует локальные ресурсы. Нет CDN, аналитики и внешних UI-скриптов.
- Версии пакетов и SHA-256 бинарных wheel-файлов закреплены в `requirements.lock`. Установка требует проверки хешей; глобальные Python-пакеты не меняются.
- Модель загружается только как пять файлов данных с закреплённой ревизии. Веса и сопутствующие данные проверяются; удалённый код модели не исполняется.
- Проверка TLS остаётся включённой. При необходимости уже доверенные сертификаты Windows экспортируются в локальный файл; сертификаты в систему не добавляются, настройки антивируса не меняются.
- Медиа, расшифровки, история, конфигурация, сертификаты, окружение и веса исключены из Git. Загрузчики могут использовать обычные временные файлы и пользовательский кэш.

Это **локальная утилита**, а не сервер для доступа из интернета. Сохраняйте обычную защиту ОС и антивирус. Ни программа, ни сканирование не гарантируют абсолютную безопасность любых будущих файлов.

## Если что-то не работает

| Проблема | Следующий шаг |
|---|---|
| Не найден Python | Установите **Python 3.11 x64** и откройте новый терминал. Файл зависимостей не покрывает другие версии. |
| Не найден FFmpeg/FFprobe | Добавьте папку `bin` FFmpeg в PATH и переоткройте терминал. |
| Ошибка загрузки YouTube | Проверьте Node.js и доступ к сети либо выберите локальный файл. Закрытый доступ программа не обходит. |
| Ошибка CUDA или памяти | Закройте приложения, занимающие GPU, проверьте драйвер NVIDIA или выберите CPU. |
| Не совпал хеш модели | Повторите установку: полностью скачанная, но неверная модель загружается заново и не используется. |
| Уже выполняется задача | Интерфейс обрабатывает одну задачу за раз; остановите её или дождитесь окончания. |

Проверка без изменений: `python install.py --verify`. Автотесты: `python -m unittest discover -v`. Проверяются продолжение после прерывания, выгрузка, границы блоков, защита локального API и ограничения установщика; для этих тестов не нужны загрузка модели и облачный сервис.

**Границы поддержки:** проверено на Windows x64 с Python 3.11. Другие ОС, версии Python и ARM не заявлены поддерживаемыми. Распознавание может ошибаться в именах, терминах и на шумной записи.
